\# AirSim\_Hybrid\_Avoidance

\## 项目整体描述

本项目基于AirSim + UE5.7.2仿真环境开发无人机混合避障算法。

主要算法框架由A-star算法+URL深度强化学习组成，旨在使用URL的前瞻性抵消传统A-star算法的对模型误差高度敏感、由于惯性引发的大幅超调等缺点，提升无人机在避障过程中的轨迹平滑性，降低无人机的运行风险和能耗。



\### 运行环境

\- 仿真引擎：UE5.7.2 + AirSim

\- 开发语言：Python

\- 算法框架：A-star算法 + URL深度强化学习
